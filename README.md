# MYFIT AI — GitHub Pages Ready Build

This build is intentionally simplified for reliable static deployment on GitHub Pages.

## Important
- `index.html` is at the repository root.
- CSS is in `css/styles.css`.
- All application logic is in `js/app.js` as one plain JavaScript file.
- No ES module imports are required.
- No paid APIs or backend are required.
- No external JavaScript library is required.

## Deploy
1. Create a new public GitHub repository.
2. Upload `index.html`, `.nojekyll`, the `css` folder, the `js` folder and this README.
3. Settings → Pages → Source: **Deploy from a branch**.
4. Branch: **main**.
5. Folder: **/ (root)**.
6. Save.
7. Wait a few minutes and open the generated GitHub Pages URL.

## Privacy
Profile, plan and progress are kept in browser local storage by this application. The application has no MYFIT AI backend and does not send the profile to an AI API. Browser/OS backup, browser extensions and other software outside the application are not controlled by this project.

The optional photo is for visual personalization only and is not analyzed for BMI, body fat, obesity or medical conditions.
